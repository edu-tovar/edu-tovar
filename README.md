### Featured Projects

**[ml-from-scratch](https://github.com/edu-tovar/ml-from-scratch)**<br>
Classical ML algorithms in NumPy: least squares and gradient descent, regularised logistic regression, k-NN, LDA, cross-validation and metrics. Every component is tested against scikit-learn; my own implementations, reorganised into a package with a test suite and benchmarks.

**[numerical-methods-python](https://github.com/edu-tovar/numerical-methods-python)**<br>
Newton interpolation, natural cubic splines, Euler and Runge-Kutta 4, and bisection, secant and Newton-Raphson, tested against SciPy. Shows Runge's phenomenon and the observed orders of convergence of the ODE solvers. Individual work.

**[student-dropout-prediction](https://github.com/edu-tovar/student-dropout-prediction)**<br>
Predicts dropout, enrolment and graduation for 4,424 university students. Covers feature engineering, leakage control, five classifiers compared on a test set and with cross-validation, regularised regression of second-semester grades, and k-means segmentation. Individual project.

**[Autonomous-Decision-Agent](https://github.com/edu-tovar/Autonomous-Decision-Agent)**<br>
An agent in a partially observable grid world that uses BFS planning, Bayesian belief updates over hidden hazards and a risk-aware policy. A stochastic river is solved as an MDP with value iteration and evaluated over thousands of simulated episodes. Individual project.

**[Urban-Navigation-Engine](https://github.com/edu-tovar/Urban-Navigation-Engine)**<br>
GPS routing over Madrid's OpenStreetMap street network, with Dijkstra, Prim and Kruskal implemented from scratch and turn-by-turn directions. Pair project with Alejandro Royo-Villanova Seguí; we both worked on every part, from the address data pipeline to the routing algorithms.

**[ChessVision](https://github.com/edu-tovar/ChessVision)**<br>
Digitises an over-the-board chess game from a single camera, combining classical computer vision (camera calibration with Zhang's method, SIFT matching) with a CNN that classifies each square. Joint project with Miguel Troyano ([@MiguelTroyano](https://github.com/MiguelTroyano)); we work on all parts together, and my focus is the CNN: a transfer-learned MobileNetV3 trained in PyTorch on the ChessReD dataset, fine-tuned on our own board and exported to ONNX for inference with OpenCV.
